# The Beginning of Guanche Warriors

Every game starts with an idea.

Guanche Warriors began with a simple ambition: to create an original JRPG inspired by the Canary Islands, combining my passion for video games with my journey into game development.

## The Vision

Guanche Warriors is an independent 2.5D turn-based JRPG inspired by the landscapes, culture and heritage of the Canary Islands.

The goal is to create a distinctive fantasy adventure that captures the spirit of classic JRPGs while exploring an original setting and visual identity.

Drawing inspiration from the games that shaped my love for the genre, I want to build an experience focused on exploration, storytelling and engaging gameplay.

## Building the Game

Guanche Warriors is also a personal journey into game development.

I'm developing the project using Unity, applying what I've learned about programming, software architecture and game development.

The current focus is on building the foundations of the game:

- Character movement and exploration.
- NPC interactions and dialogue.
- Core gameplay architecture.
- Prototyping and testing gameplay systems.
- Developing a consistent visual identity.

Each new feature brings different technical challenges and opportunities to improve my programming skills.

## Why a Devlog?

I decided to create this development journal to document the journey from the first prototypes to a playable demo.

Rather than sharing only finished features, I want to explore the process behind them:

- Programming challenges and solutions.
- Technical decisions and experiments.
- Game design and production workflows.
- Mistakes, improvements and lessons learned.

This website is also a learning project of its own, built with Astro while expanding my web development knowledge.

## What's Next?

The immediate goal is to continue developing the core systems, refining the overall experience and gradually working towards a playable demo.

There's still a long road ahead, but that's part of what makes game development so interesting.

Welcome to the development journey of Guanche Warriors.

*Building a world, one turn at a time.*
